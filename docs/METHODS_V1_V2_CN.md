# 逐帧轨道估计中的马尔可夫递推与扩散

两版从同一初始化历元开始。V1 已知真实六维初态，检验测角误差的学习与校准。V2 使用带误差的 Gauss-LS 初态，检验同一测角模型能否帮助恢复轨道。对每条有效观测，先预测、再使用当前 LOS 更新，并把本次后验用于下一帧。输入中的 `valid_mask` 决定哪些行是观测。各方法使用相邻有效帧的实际时间差。

## 物理时间与人工噪声时间

记上一有效历元为 $t_j$。物理预测为 $x_k^-=\Phi(t_k-t_j,x_j^+)$。增广的滤波状态包含轨道估计、历史摘要、上一帧角新息，以及 V2 的不确定度。新帧到达后即可从这个状态继续递推。`K` 个扩散区间在一次观测更新内部执行，单位是人工噪声时间。采集数据中的观测空档由物理时间戳自然体现。

## 两版共用的测角误差模型

令 $u^-$ 为同化前预测视线，$E$ 为其二列正交切基，$s_u$ 为此前有效同站观测得到的角噪声尺度。训练标签是 $e_0=E^\top(u_{\rm obs}-u^\star)/s_u$，其中 $u^\star$ 来自训练真值。上下文包含预测视线、当前已知站位和速度、上一帧新息、实际时间差和过去噪声尺度。当前实测 LOS 在测量模型给出预测后才参加评分与更新。

两个版本都学习余弦 VP 路径。记 $a_i=\cos(\pi i/(2K))$，$b_i=\sqrt{1-a_i^2}$。训练在随机噪声水平上构造 $z_i=a_i e_0+b_i\epsilon$，用高斯负对数似然拟合速度目标 $a_i\epsilon-b_i e_0$ 的条件均值与协方差。由网络读出干净误差的条件矩 $m_i=a_i z_i-b_i v_\theta$、$C_i=b_i^2 V_\theta$。

采样从标准高斯 $z_K$ 开始。每一步令 $r=a_i/a_{i-1}$，$c=a_{i-1}(1-r^2)/b_i^2$，$d=r b_{i-1}^2/b_i^2$。条件反向转移取

$$z_{i-1}\mid z_i,c_k^-\sim\mathcal N\!\left(c m_i+d z_i,\ \frac{(1-r^2)b_{i-1}^2}{b_i^2}I+c^2 C_i\right).$$

这个有限步马尔可夫核对未知干净误差做条件矩匹配。中间步骤从转移核采样，末步按全方差公式合并各样本的条件矩，得到当前测角偏差和二维协方差。线性高斯情形可用解析边际检验，非高斯情形需要数据验证。[扩散马尔可夫链](https://arxiv.org/abs/2006.11239)

## V1 与 V2 的输出和训练

| | V1 已知初态 | V2 含误差初态 |
| --- | --- | --- |
| 轨道预测 | 上一帧已知轨道用二体 RK4 传播。已知动力学且无过程噪声，初始点分布保持为点分布。 | 从上一帧后验传播所有状态样本，利用二体 STM 单独传播参考协方差。 |
| 当前帧更新 | 用实际 LOS 计算测角新息和预测评分，反馈到下一帧的传感器上下文。轨道保持物理传播值。 | 用测角扩散的偏差修正当前 LOS，并用其协方差白化当前似然。六维 VP 去噪器使用此前历史及传播先验，通过局部似然、平方根求解和去噪器 VJP 引导逆向概率流，输出后验轨道及样本散布。 |
| 训练与选型 | 每一有效帧监督角误差分布。DEV 按二维切平面的矩匹配高斯 NLL 选权重。 | 每一有效帧同时监督角误差与白化的六维先验误差。先验可来自物理传播或已访问的闭环状态。DEV 按源等权的全帧六维 Scaled MSE 选权重。 |

在 V2 中，当前估计的二维测角形状先在参考 LOS 切平面定义，再投影到各粒子的切平面；径向延拓使用两切向方差的均值。状态扩散和物理轨道不确定度分别计算。角噪声链能从 V1 转移到 V2，V2 也可以联合训练两个去噪器。[概率流与分数模型](https://arxiv.org/abs/2011.13456) · [实现](../v6/models/diffusion_orbit.py)

V1 从缓存中读取初始化历元的已知真值，或将该历元以前的参考星历状态传播至初始化历元。V2 推理只接收含误差初值、观测和已知站位。训练真值及验证真值用于监督、校准和评分。旧块时钟的检查点使用不同递推与选型协议，新的训练使用独立运行目录。

## 对照与运行

单点 LTR-LM/JF-BR、经典微分改正和 FD-ASF 使用同一套有效帧索引。ASD-SC 把本帧的重锚候选留到下一有效帧盲评，训练回放连接相邻两帧。B1/B2 是含误差初值下的多假设对照，它们对新 LOS 更新物理粒子权重，必要时重新提议。训练教师的预测分歧使用已公布视角或下一条真实记录的时间和站位作为训练标签，末帧使用普通后验权重。在线路径只消费截至当前的观测。

```bash
python scripts/train_v1.py --prepared-root /path/to/prepared --protocol-dir /path/to/protocol --run-dir runs/v1
python scripts/train_v2.py --prepared-root /path/to/prepared --protocol-dir /path/to/protocol --run-dir runs/v2 --sensor-checkpoint runs/v1/best.pt
python scripts/validate_v2.py --prepared-root /path/to/prepared --protocol-dir /path/to/protocol --run-dir runs/v2 --eval-split paired_val
python -s -m unittest discover -s tests -v
```
