# 逐帧仅测角定轨中的概率形变

V1 用已知初态学习传感器误差。V2 接受带误差的 Gauss–LS 初态，在每次收到测角后交出一份六维轨道后验。单帧视线直接约束两个横向方向，距离和速度往往要等后续视角才能辨识。V2 用解析更新处理当下可以确定的信息，让神经网络保留同一密度中尚有根据的斜距解释。

## V1 与共用的测角模型

V1 从初始化历元的已知六维状态出发，用真实时间差做二体 RK4 传播。确定性动力学使其轨道分布保持为点质量。学习目标是二维角误差。传感器上下文包含预测 LOS、站位、站速、上一帧新息、时间差和过去同站观测估出的噪声尺度。当前 LOS 在上下文形成后进入评分和更新。

设 $a_i=\cos(\pi i/(2K))$，$b_i=\sqrt{1-a_i^2}$，角噪声扩散在训练中使用 $z_i=a_i e_0+b_i\epsilon$ 与速度目标 $a_i\epsilon-b_i e_0$。反向马尔可夫链从标准高斯出发，根据学习的条件速度矩逐步恢复角噪声。最后用全方差公式得到偏差和协方差。`--observation-model direct` 用异方差网络直接估计相同的矩，`calibrated` 使用因果标定的角尺度。V1 的扩散传感器有 6,582 个参数，可以转移至同一数据切分的 V2。[传感器实现](../v6/models/diffusion_orbit.py) · [扩散马尔可夫链](https://arxiv.org/abs/2006.11239)

## V2 保存什么

每个目标在历元 $t_k$ 保存一份归一化密度

\[
 x=\mu_k+D L_k T_\theta(z;a_k),\qquad z\sim{\cal N}(0,I_6).
\]

$D$ 给出位置和速度的 SI 单位尺度。$\mu_k,L_k$ 定义参考坐标，后验均值和协方差通过积分读取。$T_\theta$ 由两层交替的三对三有理二次样条耦合组成，每个标量使用 8 段和线性外尾。每轨保存 150 个形状系数，共享权重在推理时固定。零形状对应恒等映射。任意状态的密度由解析逆映射和对数雅可比行列式给出。有限积分点只在一次运算中使用。`step` 结束后保存同一个后验对象的新参数以及下一次观测所需的传感器上下文。[样条与状态密度](../v6/models/posterior_warp.py) · [神经样条流](https://arxiv.org/abs/1906.04032)

1. **预测。** 根据相邻有效观测的实际 $\Delta t$，沿一条物理参考轨道积分状态、一阶变分 $J$ 和二阶变分 $S$。在上一后验的形状坐标 $u=T_\theta(z;a)$ 内，物理像近似为 $\Phi(\mu)+Ju+\tfrac12S[u,u]$。系数更新器读取该分布相对线性传播的变化。长空档和宽先验会增加高阶截断误差。[二体变分](../v6/models/reprojection.py)
2. **解析吸收局部信息。** 每个有效 LOS 的似然分成 $K$ 份，每份幂为 $\alpha=1/K$。在当前参考因子下，令 $B=HL$，其中 $H$ 已按状态和角噪声尺度白化。对 $[I;\sqrt{\alpha}B]$ 做 QR，得 $U^\top U=I+\alpha B^\top B$。三角求解给出新的中心和因子 $LU^{-1}$。当先验高斯、测量线性且噪声高斯时，任意正整数 $K$ 均给出解析条件均值和协方差。
3. **学习剩余形状。** 在线似然使用完整球面方向。传感器偏差定义旋转，协方差定义球面线性变换及其面积雅可比，变换后的 vMF 核使用完整弦差。更新器对比真实后验目标与 QR 后的形状，权重扣除已经同化的局部线性似然。平滑边缘 CDF、加权分位数和多维联合特征共同生成形状增量。两份测度相同时增量为零。新证据连续改变不同距离区间的概率质量。[逐帧预测与同化](../v6/models/ppc_flow.py)

物理历元上的马尔可夫递推、角噪声空间的反向扩散和轨道空间的残差流匹配分别承担历史传递、噪声估计和形状学习。默认 V2 的轨道更新是学习型确定性输运。训练监督包括真值状态的变化变量 NLL、残差条件流匹配和测角损失。在线始终先完成当前帧更新，再用真值评估。默认梯度跨 2 个有效帧传回形状系数，物理参考和数值教师停止梯度。[条件流匹配](https://arxiv.org/abs/2210.02747)

## 入口与同条件对照

```bash
python scripts/train_v1.py --prepared-root /path/to/prepared --protocol-dir /path/to/protocol --run-dir runs/v1
python scripts/train_v2.py --prepared-root /path/to/prepared --protocol-dir /path/to/protocol --run-dir runs/v2 --sensor-checkpoint runs/v1/best.pt
python scripts/validate_v2.py --prepared-root /path/to/prepared --protocol-dir /path/to/protocol --run-dir runs/v2 --eval-split paired_val
```

默认初始参考中心取传入的 $B_0$。尺度只用 TRAIN-fit 的误差标定。`--initial-bias train_mean` 可检验总体平均修正对不同初差组的作用。V1 用 DEV 测角 NLL 选型，V2 用 DEV 源等权轨道 Scaled MSE 选型。冻结权重后在配对 VAL 比较相同的 $B_0$、到达前缀、有效帧和站位，分别记录四种节奏、小初差恶化、尾部分位数、六维后验评分与下一帧 LOS 校准。记录级数值失败计入失败率和惩罚统计，有限分位数另报样本数。

| 入口设置 | 主要作用 |
| --- | --- |
| `--arch qr --observation-model calibrated` | 解析平方根更新，使用因果标定角噪声。 |
| `--arch gaussian` | 与样条相同的非线性似然、积分节点和二阶传播，逐次投影到高斯族。 |
| `--arch ppc` | 默认样条形变。`--K 4`、`--P 8`、`--warp-nodes 128`、`--unroll-frames 2` 分别控制同化幂及角链步数、角链采样及训练配对数、每套参考坐标的积分节点数、形状反传跨度。 |
| `--arch diffusion` | 旧六维 VP/VJP 状态滤波独立对照，共 50,432 个参数。 |
| `train_v1.py --arch cl_full_prefix_wls --initialization gauss_ls` | 因果全前缀经典对照，显式使用与 V2 一致的带误差初态。 |

PPC 状态部分有 61,068 个参数，配角扩散共 67,650 个，配直接矩网络共 64,385 个。模型运行只沿一条物理参考轨道传播。独立估计器对照、随机种子重复和读取概率积分各自服务于实验设计。

## 实测范围

`scripts/check_ppc_two_ranges.py` 在 12,001 点的二体斜距切片上训练实际形状更新模块，并用独立的边缘密度积分验证峰和谷。三个训练种子均保留了近、远两个主峰。初次观测后的谷区质量为 2.58%–3.00%，同证据高斯投影为 34.56%，网格参考为 $8.50\times10^{-9}$。在该算例的消歧视角到达后，32,768 个读出样本全部落到近根一侧，近根内仍有细小局部峰。这个算例含一个有物理几何的距离坐标和五个独立高斯坐标。全量 G4 的好轨保护、尾部恢复和概率覆盖仍待配对训练与评测。当前在线入口接收外部初态。
